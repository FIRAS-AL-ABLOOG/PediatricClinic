# 🩺 Pediatric Clinic

A modern and responsive pediatric clinic website built with **React.js** and **Vite**.

The website provides a simple and friendly experience for parents to explore the clinic, book appointments, read pediatric guidance, view working hours and location, and browse a small medical products store.

## 🌐 Live Demo

🔗 https://pediatricclinic-ten.vercel.app/

---

## ✨ Features

* 🏠 Modern home page
* 👩‍⚕️ Pediatric doctor presentation
* 📅 Appointment booking interface
* 📝 Doctor posts and medical guidance
* 📍 Clinic location and working hours
* 🛒 Medical products store
* 📱 Fully responsive design
* 🍔 Responsive mobile navigation menu
* 🎨 Clean pediatric-friendly UI
* ⚡ Fast performance with Vite
* 🔀 Client-side routing with React Router

---

## 📄 Pages

### 🏠 Home

The main landing page introduces the clinic and doctor with a friendly pediatric design.

### 📅 Appointments

Allows parents to enter their child's information and request an appointment.

### 📝 Doctor Posts

A section for pediatric medical advice, tips, and educational content.

### 📍 Location & Working Hours

Displays clinic working hours, address, and contact information.

### 🛒 Store

A small medical products section containing useful products for children and families.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/FIRAS-AL-ABLOOG/PediatricClinic.git
```

Go to the project folder:

```bash
cd PediatricClinic
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally using Vite.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

The production files will be generated inside:

```text
dist/
```
